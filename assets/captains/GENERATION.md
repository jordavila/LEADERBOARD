# Avatares de capitán

Generados con la herramienta integrada ImageGen, con transparencia real (RGBA). Referencias: los retratos PNG de la raíz del repositorio. La animación se aplica con CSS, no está incrustada en los PNG.

## Prompt JADO82

Use case: identity-preserve. Create one full-body captain avatar for a videogame leaderboard using this reference portrait to preserve the man's exact recognizable facial features, dark beard, eyebrows, helmet and headset. Match the existing stylized illustrated grain-texture cartoon portrait style. Full body visible from helmet to boots, confidently standing with a smug cocky relaxed captain attitude, slight smirk and raised chin, military olive tactical gear, holding a rifle safely across his torso pointing diagonally down, one relaxed knee. Centered single character with generous transparent margins all around, genuinely transparent background, no scenery, no text, no shadow backdrop. Palette black #11120F graphite #292B27 olive #77786D bone #F4F2E9 with very restrained yellow #F5D21B insignia. This is a static asset that will receive subtle breathing and swaying animation via CSS; keep limbs close enough to fit narrow hero column.
